# Third party code

- `lightcraft/`: licence texts of [LightCraft](https://github.com/storytold/lightcraft) by storytold (MIT OR Apache-2.0), commit 80de5f8faee3bfe33202d0f8373122645dba2988. The engine depends on its crates lightcraft-pipeline, lightcraft-develop, lightcraft-raster, lightcraft-color and lightcraft-geom (and their dependencies) and is compiled into `engine.wasm`.
- `rust-crates.txt`: every Rust crate in the engine's dependency tree with its licence (generated by `scripts/build.sh`).
- The zip writer, the WebAssembly glue and the rest of the page are AutoColor's own code (MIT).
- Build tool only (not shipped): binaryen wasm-opt (Apache-2.0).
